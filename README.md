# ALLNOVATECH CRM para Mac

App de escritorio para Mac que trabaja con la **PC principal** (Windows) de la oficina: misma empresa, mismos datos.
No guarda datos propios; la base, la licencia y los respaldos viven en la PC principal.

Descarga y pasos: https://all-novatech.com/crm-desktop/#mac

Este repositorio solo arma el instalador (`.dmg`) en una Mac de GitHub al publicar una etiqueta `vX.Y.Z`.
